# vulpix standard directories

## data

- windows root: `%ProgramData%\vulpix`
- windows user: `%LOCALAPPDATA%\vulpix-data`
- linux root: `/var/lib/vulpix`
- linux user: `~/.local/state/vulpix`

## log

- windows root: `%ProgramData%\vulpix\log`
- windows user: `%LOCALAPPDATA%\vulpix-data\log`
- linux root: `/var/log`
- linux user: `~/.local/state/vulpix/log`

## config

- windows root: `%ProgramData%\vulpix\config`
- windows user: `%LOCALAPPDATA%\vulpix`
- linux root: `/etc/vulpix`
- linux user: `~/.config/vulpix`

## os font directory

- windows root: `C:\Windows\Fonts`
- windows user: `%LOCALAPPDATA%\Microsoft\Windows\Fonts`
- linux root: `/usr/share/fonts`
- linux user: `~/.local/share/fonts`
